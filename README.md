## Student Result & Grade Management System
## Project Description
The Student Result & Grade Management System is a Python-based application designed to manage student information, subject marks, grades, and academic performance.
The application provides a simple menu-driven interface to add, view, search, and update student records.
## Objectives
- Learn Python programming fundamentals.
- Manage student records using dictionaries.
- Calculate total marks and percentages.
- Generate grades automatically.
- Implement search and update functionality.
- Display academic performance summaries.
## Technologies Used
- Python 3
- Programiz Online Python Compiler
- GitHub
## Features
1. Add student details.
2. View all student records.
3. Search students using roll numbers.
4. Update student marks.
5. Calculate total marks.
6. Calculate percentage and grades.
7. Generate performance summaries.
8. Validate marks between 0 and 100.
